# SQL Masters

Adaptive SQL training, like chess tactics but for SQL. Every user and every problem has an ELO rating that moves with wins and losses.

- Runs entirely in the browser (sql.js). No backend; progress is stored in the browser and can be saved/loaded as a JSON file.
- `problems.json`: 1,500 problems generated from templates and checked by program.
- `gretel.json`: problems adapted from [gretelai/synthetic_text_to_sql](https://huggingface.co/datasets/gretelai/synthetic_text_to_sql) (Apache License 2.0), filtered and reviewed automatically.
